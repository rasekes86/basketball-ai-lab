REPRODUCIBLE · SIN CAJA NEGRA

Cómo calculamos.

01

Historial anterior al partido

Solo utilizamos encuentros finalizados y conocidos antes de generar el pronóstico. No entrenamos con resultados futuros.

02

Modelo experimental

El Top 3 actual utiliza anotación y puntos recibidos de encuentros anteriores, ponderados por antigüedad. Las fichas añaden una comparativa descriptiva de los últimos diez partidos, forma y descanso; esas cifras no son estadísticas avanzadas de posesiones, lesiones o jugadores. No está calibrado para apuestas.

03

Tres selecciones entre varios mercados

El motor compara ganador, puntos, hándicap y, con una muestra suficiente de box scores, triples, rebotes y asistencias de equipos. Elige tres mercados diferentes para nuevos partidos. Las líneas teóricas NO son cuotas de casas de apuestas.

04

Adicional +1,50

Solo podrá archivarse si existe una cuota real registrada, de un proveedor y casa identificados, antes de empezar el partido. Por defecto está desactivada.

05

Seguimiento postpartido

Separación visual de acierto, fallo y pendiente. Ningún resultado ausente se contabiliza como fallo y el Top 3 no se recalcula retrospectivamente.

06

Fuentes y límites

ESPN ofrece endpoints accesibles sin clave pero no documentados para usos externos. Si el proveedor falla, se conservan los archivos, se señala el problema y no se inventa información.
